- `cover-master.png`: selected English four-colour Sicily master with English ✓ above 中文 ✓, copied unchanged from `title-20261031-languages-v2/cover.en.png`.

The owner selected the four-colour covers on 2026-10-31. The map follows the 23 game locations of Sicily's main island, coloured so that neighbouring locations differ; see [the selected artwork folder](title-20261031-four-color/README.md). They are graphics made with built-in `image_gen`, **not in-game screenshots**. The previous Sicily-outline artwork is preserved in `dist/artwork-history-20261031-sicily-outline/`.

The owner approved the language-label revision on 2026-10-31: [selected bilingual covers](title-20261031-languages-v2/README.md), with English above Chinese at the lower left. The previous four-colour assets are preserved in `dist/artwork-history-20261031-before-language-labels/`. Description badges use the precise [SVG/PNG version](badges-20261031-vector/README.md), separately in English and Simplified Chinese; generated badge drafts are historical.

Display names: **Descriptions for Every Tile** / **所有地块的描述**. The English image is the shared Workshop primary cover and runtime thumbnail. The Chinese README uses the Chinese image. Both covers are listed in `workshop/page.json` for validation; this does not claim that Steam automatically changes a single item's primary image with the reader's language. The Chinese JPEG may also be uploaded as an additional image.

The previous active artwork is preserved locally in `dist/artwork-history-20261031-before-sicily/`; earlier generated variants remain in their versioned folders. No location prose, game installation or external listing is changed by selecting these assets.
