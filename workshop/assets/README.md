The current image was generated specifically for this project with the built-in `image_gen` tool on 2026-10-26 after the owner requested a plainer cover. It is a typographic graphic, **not an in-game screenshot**. It uses a light background, dark sans-serif text and a small schematic of adjoining map cells. No supplied game artwork, third-party source image or official logo was used as input. Raster derivatives only resize/encode the master.
