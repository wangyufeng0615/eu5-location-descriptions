# 全地图地点介绍

[English](README.md)

为 EU5 原本没有介绍的地点增加英文与简体中文文本。同一包内包含两种语言，当前基线新增28,449条、保留124条原版介绍，不需另装汉化。

## 安装

手动下载时，将整个 location_descriptions_enhanced 文件夹放入 EU5 用户数据目录的 mod 下，保留隐藏的 .metadata，在“模组和DLC”中启用，并将游戏语言设为英文或简体中文。工坊安装则先订阅并等待下载，再启用。不要同时启用本地和订阅副本。

当前是Alpha。正文在查阅资料后由AI辅助撰写，详略不一，未逐篇完成独立事实核验。完整正文候选仍需记录实机与订阅检查后才能公开发布。

## 兼容与反馈

按Steam build 24187685准备。地图大修和其他介绍模组可能冲突，英中甚至可能显示不同版本。当前尚未确认存档、成就和联机兼容。

见[常见问题](docs/FAQ.zh-CN.md)、[兼容性说明](docs/COMPATIBILITY.md)和[贡献指南](CONTRIBUTING.zh-CN.md)。工坊留言附地点名称、地区、截图和资料即可，中文或英文都欢迎，不强制内部ID。
