# 所有地块的描述

[English](README.md)

为 EU5 原本没有介绍的地点增加英文与简体中文文本。同一包内包含两种语言，适配游戏1.4版，新增28,316条；257条原版介绍保留原文，并在其后补写一到两段，不需另装汉化。

## 安装

手动下载时，将整个 location_descriptions_enhanced 文件夹放入 EU5 用户数据目录的 mod 下，保留隐藏的 .metadata，在“模组和DLC”中启用，并将游戏语言设为英文或简体中文。工坊安装则先订阅并等待下载，再启用。不要同时启用本地和订阅副本。

正文先以AI辅助、依据公开资料（主要是英文和当地语言的维基百科）起草，再由作者（一名地理爱好者）尽可能订正、校验，城市条目逐项核对过年份和人物。详略不一，难免仍有疏漏。

## 兼容与反馈

适配游戏1.4版（Steam build 26300913）。地图大修和其他介绍模组可能冲突，英中甚至可能显示不同版本。

见[常见问题](docs/FAQ.zh-CN.md)、[兼容性说明](docs/COMPATIBILITY.md)和[贡献指南](CONTRIBUTING.zh-CN.md)。发现错误或加载问题，直接在工坊留言就好，中英文都可以。涉及具体地点时请带上地点名称，截图或资料链接有的话可以附上。我会积极维护这个模组，认真查看反馈，持续修正问题并跟进游戏更新。
